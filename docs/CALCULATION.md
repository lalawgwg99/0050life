# 計算說明

## 為什麼分開算

勞保、勞退與投資的規則不同，先各自算清楚，最後才合在每個月的退休收支中，比直接把三筆錢加成一個總額更容易核對，也能避免領取時間不同造成誤差。

1. 勞保：依平均月投保薪資、保險年資與請領年齡，分別計算兩個法定公式，採較高者。提早或延後領取的調整最多計五年。
2. 勞退：從目前個人專戶餘額開始，逐月加入雇主與自己的提繳，再依設定的成長率計算。一次領與按月領分開處理。
3. 投資：從目前資產開始，逐月加入投入金額，以扣除費用後的報酬率累積。
4. 合併：從退休月份起，每月先算生活費，再加入當月已開始領取的勞保、勞退與兼職收入。不足的部分才從投資資產拿出，有剩餘則放回投資資產。

所有月份都用同一條時間軸處理。畫面上的主要金額會換算成今天的物價，避免把數十年後的金額與現在的金額直接相比。

## 目前使用的規則

- 勞保老年年金：勞保局兩式擇優、展延與減額規則。
- 勞保年金物價調整：累計消費者物價指數達 5% 才調整；使用者也可選擇先不估。
- 勞退月退休金：依請領年齡套用勞保局目前公告的平均餘命與 1.1473% 利率，不讓使用者自行指定領取年數。畫面以每月金額呈現，實際依規定按季發給。
- 規則版本與核對日期顯示在試算結果中。

## 不能當成保證的部分

未來投資報酬、物價、薪資與政策都可能改變。畫面提供較低、目前與較高三種報酬情況，目的是看條件改變時的差距，不代表成功機率。正式給付金額仍以主管機關核定為準。
