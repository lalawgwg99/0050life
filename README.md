# 0050 Life

一個只在瀏覽器執行的退休規劃試算工具。勞保、國保、勞退與自己的投資會先分開計算，再按照實際開始領取的月份，逐月合併到退休現金流。

畫面上的主數字會用「今天的購買力」呈現，旁邊再補退休當年的帳面金額；這不是兩個不同答案，而是讓你同時看懂生活水準和未來可能看到的金額。

它特別適合有停保、轉到國保，或同時持有多種股票／基金的人：每筆投資分開複利，國保年資不會和勞保混算；當準備不足時，結果頁會直接估算可執行的下一步，例如每月要多存多少。

結果頁會先把退休第一個月的生活費、按月收入，以及每月還要從投資補上的差額分開列出；一次領的勞保或勞退只放進退休資產，不會被誤看成固定月收入。`0050` 是方便開始填寫的預設名稱，使用者仍可加入其他股票或基金。

勞退選擇一次領時，可以用快速按鈕或百分比設定要投入股票的比例；未投入的部分會保留為退休現金，先用來支付生活費。

## 本機執行

```bash
npm install
npm run dev
```

開發頁面是 `http://localhost:5173/index.vite.html`。正式建置完成後，編譯過的首頁與資源也會同步到專案根目錄，供目前未設定建置指令的 Cloudflare Pages 直接發布。

## 檢查

```bash
npm test
npm run test:e2e
npm run build
```

- `npm test`：檢查日期、利率、勞保、國保、勞退、投資與整體試算。
- `npm run test:e2e`：用桌機及手機尺寸實際操作頁面。
- `npm run build`：檢查型別、建立正式網站檔案，並同步 Cloudflare Pages 直接發布所需的檔案。

## 計算原則

詳細內容請看 [計算說明](docs/CALCULATION.md)。法規數字集中在 `src/rules/`，未來規定改變時不需要重寫整套程式。

本工具提供規劃參考，不等同勞保局核定金額或投資保證。正式申請前仍應以勞保局個人資料與最新公告為準。
